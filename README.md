# Scatter Plot to Observe Relationship Between Two Columns

## Aim
To observe the relationship between two columns of a Pandas DataFrame using a scatter plot.

## Requirements
- Python 3
- Pandas library
- Matplotlib library

## Functions Used
1. `pd.DataFrame()` – Creates a DataFrame.
2. `plt.scatter()` – Creates a scatter plot.
3. `plt.title()` – Adds a title.
4. `plt.xlabel()` – Labels the X-axis.
5. `plt.ylabel()` – Labels the Y-axis.
6. `plt.legend()` – Displays the legend.
7. `plt.grid()` – Adds grid lines.
8. `plt.show()` – Displays the graph.

## Algorithm
1. Import Pandas and Matplotlib.
2. Create a DataFrame with 5 columns and 10 rows.
3. Select the Hours and Marks columns.
4. Create a scatter plot.
5. Add a title, labels, legend, and grid.
6. Display the graph.

## Result
The scatter plot is successfully created to observe the relationship between study hours and marks.
